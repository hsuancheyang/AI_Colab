1. 挑選三個大語言模型
2. 使用 Colab

- 人設 System
- 溫度 Tempture
- Top-P 值
- Top-K 值

繳交：word檔：回答上述問題。

## 第二週作業

![image](/images/20250703/LearningAssistant.png)
利用 Google NotebookLM 提拱多個文獻來源（至少三個：網頁、Youtube 影片、PDF、Word、Excel、PowerPoint...等檔案）。

為你自己生成多種資料重點：

1.  簡介文件（作為你的閱讀重點）
2.  大綱（作為投影片的大綱、影片的大綱）
3.  心智圖（記憶重點提醒）
4.  生成是非題、選擇題、填空題、簡答題...（期中、期末考的猜題）。

繳交：word檔：上述要求結果。

## 第三週作業
### 利用Fooocus生成三個特殊目的的圖樣：
例如：
1. 投影片的附圖
2. 自己訂定的商品商標
3. 個⼈品牌圖像，等等…

- 為每張圖撰寫簡短說明，包括：
1. 使⽤了哪些 Fooocus 功能（如 prompt 設定、Style、Inpaint、Canny 等）
2. 有什麼⼼得？
3. 簡要整理你建⽴的創作流程（⽂字敘述或流程圖均可），讓別的同學能了解你從靈感、設定、試圖改善到輸出圖⽚的步驟。

繳交：word檔（內含生成圖片及上述說明）

## 第四週作業
### 利用今天介紹的工具完成一個任務：

1. 針對自訂主題，利用Gamma及Napkin製作一個圖文並茂的精彩投影片。

- 為你的投影片撰寫簡短說明，包括：
  1. 你的主題，你下了什麼提示字句？你經歷的步驟。
  2. 有什麼⼼得？
  3. 簡要整理你的短片創作流程（⽂字敘述或流程圖均可），讓別的同學能了解你從靈感、設定、試圖改善到輸出短片作品的步驟。

繳交：word檔（內含上述說明）及簡報檔

## 第五週作業

1. 利用PixVerse產生10秒以上的短片。
繳交：影片檔及word檔（內含prompt內容及額外設定，包括運鏡及風格）

2. 利用SUNO製作一手令你滿意的音樂。
繳交：音樂檔（mp3）及word檔（內含prompt內容及曲風、元素、節拍等設定及風格）
