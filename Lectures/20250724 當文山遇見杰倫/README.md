本週介紹的是「音樂生成」。音樂生成的核心技術主要包括以下幾個關鍵層面：
- 深度學習與神經網絡模型：以深度學習技術訓練出的神經網絡作為基礎，能夠分析並學習大量音樂作品，把握音樂的結構與規律。
- 音頻Token化技術：將連續的音頻信號轉換為可處理的token（片段），這使模型能精細管理不同維度的音樂資訊（例如旋律、節奏、和聲），提升生成效率與精確度，同時保留情緒與結構。
- 跨模態生成（文本到音樂）：透過輸入文字描述便能解析文本內容（如情緒、場景、音樂風格等），通過模型將語言資訊轉化為對應的音樂參數，完成從語意到聲音的轉換。
- Transformer與擴散模型的結合：核心生成模型還是採用Transformer架構，具備優異的序列建模能力與多頭注意力機制，能處理長期依賴和音樂段落間的關聯。同時，融入擴散模型以增強旋律細節和局部表現力，確保音樂在宏觀結構與微觀表現間取得最佳平衡。
- 自動文本理解與音樂結構構建：進行文本解析，提取用戶描述的關鍵詞（如流派、情感、速度、樂器），然後構建音樂歌曲的段落、旋律、和聲、編曲與人聲，甚至能根據需求自動生成歌詞。

使用 **Suno 創作音樂** 的流程包含以下幾個關鍵步驟：

1. **註冊與登入帳號**  
   先在 Suno 平台完成帳號註冊，可以使用 Google、Discord 或 Microsoft 等第三方帳號登入。

2. **設定創作目標與靈感**  
   在開始創作前，明確自己的音樂目標或主題，例如流派、情緒、故事背景，甚至可準備參考作品或關鍵字，有助 AI 生成更貼合需求的音樂。

3. **選擇創作或生成模式**  
   - **Prompt 模式**：適合新手，只需一句話描述音樂內容即可。  
   - **自訂（Custom）模式**：可分別設定歌詞、風格、曲名等，彈性更高。

4. **輸入提示內容（Prompt/參數）**  
   - 歌曲描述：如「輕快的夏日流行樂」或是音樂目的，如：「釋放緊張情緒」、「提供緊湊刺激以及懸疑感」  
   - 歌詞內容：可讓 Suno AI 自動生成或自行輸入（透過自己的專屬機器人人設產生文豪般的筆觸）  
   - 選擇音樂風格（韓風、日系City-Pop、Jazz、Reggae、Acid Jazz、Bossa Nova、中國風、Metal、英搖Britpop、Techno、Eurodance、Swing、Big Band）、節奏、樂器、語言等參數
   - 可以指定歌曲名稱或歌手角色。

1. **提交生成音樂**
   點擊「Create」按鈕，Suno 會根據輸入內容産生兩個不同版本的完整音樂，包含配樂及原創歌詞（如有設定）。

2. **試聽並選擇作品**
   可立即播放預覽 AI 生成的兩個版本，根據喜好自由挑選。

3. **調整與延伸**  
   若需修改歌詞、風格、音樂長度或細節，可微調設定後重新生成。亦可用「Extend」功能延長歌曲，或局部替換內容做二次編輯。

4. **下載與分享**  
   滿意成品後可將音樂下載收藏，也可直接分享到社群平台，或設為公開讓更多人欣賞和使用。

**補充：**  
- 無音樂基礎者只要善用關鍵字、情緒或故事描述，就能輕鬆生成高質感、結構完整的音樂作品。
- 若希望更精準掌控結果，建議多利用自訂模式細部調整；如只需配樂可跳過歌詞欄位。
